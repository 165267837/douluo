# 斗罗大陆 · 魂师传说

基于 Three.js 的 3D 动作 RPG（单文件网页游戏），打开即玩，已适配手机横屏。

## 在线试玩

部署到 GitHub Pages 后，访问仓库的 Pages 地址即可：

```
https://<你的用户名>.github.io/<仓库名>/
```

## 手机 / 微信游玩提示

- 建议**横屏**游玩（游戏会自动提示强制横屏）。
- 首次进入会有约 10 秒的加载动画（视频），点击右上角「跳过」可立即进入。
- 加载动画默认**静音**播放（浏览器的自动播放限制），左下角「点击开启声音」可打开背景音乐。
- 如果画面卡顿，可在游戏内「设置」里降低画质。

## 技术说明

- 纯静态站点，无需后端。仓库内所有依赖都已本地化：
  - `vendor/three.min.js` — Three.js r147
  - `vendor/tailwind.js` — Tailwind 运行时
- **不依赖任何外部 CDN**，因此在国内网络 / 微信内置浏览器下也能正常加载。
- 视频素材已做 `+faststart` 处理与码率压缩，便于移动网络流式播放。

## 目录

| 文件 | 说明 |
| --- | --- |
| `index.html` | 游戏主体（全部逻辑与资源引用） |
| `loading.mp4` | 登录加载动画（10.6s，含 BGM） |
| `intro.mp4` | 进入游戏时的开场动画（4s） |
| `vendor/` | 本地化的第三方库 |
| `soul-icons/` | 武魂图标 |
| `manifest.json` | PWA 清单 |
| `.nojekyll` | 关闭 GitHub Pages 的 Jekyll 处理 |
